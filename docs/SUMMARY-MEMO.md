# 사실 중심 업무 메모 (2026-11-11)

요약은 원문에 있는 `위치 / 대상 / 현황 / 경과 / 피해`만 짧은 명사형으로 작성한다. 감정·비난·압박·위협과 요청 문장은 제외한다. 전화 횟수, 기존 답변, 조치 여부와 구체적인 피해는 비난 속에 있어도 보존한다. 원문에 없는 항목은 채우지 않는다.

요청은 별도 목록에 중립적인 `~ 요청`으로 작성한다. 제목에만 있는 요구도 포함하고, 실제 조치와 일정·가능 여부 문의를 서로 대체하지 않는다. 조건, 순서, 대안과 부정도 유지한다. 시민이 확인·수정한 요구 목록의 우선순위는 기존과 같다.

화면은 알려진 항목의 메모를 라벨·값 행으로 표시한다. 기존 서술형, 알 수 없는 항목이 섞인 요약, 같은 항목이 반복된 요약은 내용을 버리지 않고 문단으로 표시한다. 빈 추가 질문은 분석 저장 전과 화면 표시 때 제거한다. 이미 저장된 요약은 수정하지 않으며 새 접수 또는 다시 분석 때 새 형식이 생성된다.
