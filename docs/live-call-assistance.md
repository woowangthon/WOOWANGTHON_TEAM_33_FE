# 통화 중 담당자 답변 도움

담당자 통화 화면에서 확정된 발화의 처리 요청마다 짧은 답변 초안, 다음 확인 사항, 관련 공식 근거를 표시합니다. 새 발화 후 450ms 동안 변경이 없으면 자동 갱신하며, 통화 전환·후속 발화 때문에 낡은 응답이 도착하면 버립니다. 재시도 중에는 이전 발화 기준임을 표시합니다.

`POST /api/phone/assistance`는 담당자 인증과 동일 출처를 요구합니다. 서비스 전용 Gemini 키가 있으면 `gemini-3.5-flash-lite`, 없으면 기존 서비스 OpenAI 모델을 사용합니다. `PHONE_ASSIST_PROVIDER=openai|gemini`, `PHONE_ASSIST_MODEL`로 지정할 수 있습니다. 사용자 개인 키는 웹 서비스의 대체 키로 사용하지 않습니다.

기관별 기존 공식 자료를 1분간 캐시하고 조회를 최대 1초 기다립니다. 지연되거나 관련 자료가 없으면 이를 표시하고 확인할 사항 중심으로 초안을 만듭니다. 새 법령 수집이나 민원 등록을 자동 실행하지 않습니다. 인용 ID와 원문 발췌를 서버에서 확인하지만 법률적 적용 타당성까지 검증된 최종 답변은 아닙니다. 담당자가 확인한 뒤 안내합니다.

검증: `node --test tests/phone-assistance*.test.cjs`, `node node_modules/typescript/bin/tsc --noEmit`. 선택적 유료 API 확인: 환경에 기존 서비스 키를 설정한 후 `node scripts/check-phone-assistance.mjs`. 합성 입력만 사용하며 키를 출력하지 않습니다.

평가는 기존 요약 결과와 실제 생성된 답변을 함께 채점합니다. ① 사실 정확성 ② 내용·요청 보존 ③ 요청별 답변 ④ 근거·불확실성 ⑤ 명료성에 각 0/5/10/15/20점을 부여합니다. 항목별 판단 이유와 입력·출력·출처를 보존하며, API 성공이나 인용 형식 통과를 품질 만점으로 간주하지 않습니다.
