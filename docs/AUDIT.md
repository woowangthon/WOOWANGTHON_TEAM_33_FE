## 검증 기록

- Node 24.22.1에서 웹·음성·기존 실험 회귀 테스트 76개 통과. 테스트 명칭/범위를 구분하며 실제 API 정확도 수치가 아니다.
- Node 24에서 TypeScript 검사 통과. PC의 기본 Node 22에서는 프로세스 비정상 종료가 발생했으므로 Node 24 사용을 명시했다.
- 소스 내보내기 폴더가 TypeScript 검사에 섞이던 문제를 발견해 `outputs`를 검사 대상에서 제외했다. 앱 소스의 타입 검사를 건너뛰는 설정은 추가하지 않았다.
- 수정 후 Node 24에서 프로덕션 빌드 통과. 실제 외부 API를 새로 호출하거나 운영 사이트를 재배포한 결과는 아니다.
- 게시 후보 186개 파일에서 로컬 환경변수의 실제 비밀값 및 주요 API 키/개인키/DB 비밀번호 형식을 검사했고 발견된 값은 없었다. 이후 빌드가 재생성하는 Workflow 파일 8개도 제외해 최종 소스는 178개다. 검사기 `scripts/prepare-source.mjs`는 비밀값을 로그에 출력하지 않는다.
- 기존 실연결 결과: 합성 음원을 실제 운영 WebSocket/STT/AI에 전달한 13개 기능 점검 통과. 실제 070/PSTN·물리 스마트폰 통화 검증과는 다르다.
- 기존 측정: 욕설 음원 시작→차단 6,004ms, 일반 발화 종료→텍스트 6,121ms. 단일 측정이며 노출 감소율/평균 지연으로 일반화할 수 없다.
- 기존 40건 평가: 100개 요구 중 답변 누락 18개, 탐지 15개, 오경보 13개. 단위는 민원 건수가 아니라 요구사항이다. 이 수치는 정답 후보의 독립 검수 전 잠정 결과다. 별도 누락 주입 실험 8건/22요구를 자연 발생 성능과 합치지 않는다.
