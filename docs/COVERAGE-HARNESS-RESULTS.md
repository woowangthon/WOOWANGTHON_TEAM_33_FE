필수 질문과 구체적인 확답 불가 설명은 민원 해결이나 적법한 거절을 뜻하지 않는다. 보완 답변에는 근거 재검토가 필요한 문장 13개가 남아 있어 담당자 검토와 승인 조건을 유지한다.

## 하네스 변경

1. 원문만 입력한 별도 단계에서 요구 종류와 원문 인용으로 검사 계획을 고정한다. 답변을 읽은 모델이 요구의 의미를 바꾸지 못하도록 서버가 고정 계획을 적용한다.
2. 답변 검사 모델은 구체 답변·한계 설명·질문·인용 근거를 추출한다. 최종 status는 출력 스키마에 없다.
3. 코드 판정표가 정보 종류·질문 범위·기존 제공 정보·인용 일치를 확인한다. 공통 현장 질문으로 신규 조치·계획·연락 문의를 대체하지 못한다.
4. 인용 기술 오류 재추출은 한 검사에서 최대 1회, 누락 보완도 한 초안에서 최대 1회다. 기존 문장을 보존하며 요구 대응이 퇴행한 보완안을 거부한다.
5. 보완의 조문 ID를 제공된 목록으로 제한하고 서버가 표준 인용을 붙인다. 변경된 답변은 법령 근거도 다시 검사한다.
6. 요구별 적용 규칙과 고정 계획은 harness.decisions, harness.plan, harness.observations에 저장한다. API 없이 같은 규칙을 재실행하는 evals/replay-coverage-rules.cjs를 제공한다.

설계와 예외: [COVERAGE-HARNESS.md](COVERAGE-HARNESS.md). 규칙은 의미 해석을 완전히 대체하지 않는다. 요구 분류와 근거 추출이 틀리면 여전히 오경보 또는 누락이 생길 수 있다.

## 실험 방법

- 원문 40건, 기존 답변·조문, 기존 추출 요구, 기존 참조 판정을 그대로 사용했다. 정답과 평가 사례 ID는 제품 검사기·보완기에 보내지 않았다.
- 직전 결과 일부를 재사용해 점수를 조합하지 않고 전체 40건을 새 API 호출로 검사했다. 보완된 답변만 변경하지 않은 참조 채점 프롬프트로 별도 채점했다. 보완하지 않은 답변은 고정 참조 판정을 사용했다.
- 법령 수집·초안 생성부터 40건을 새로 실행한 것은 아니다. 검사와 제한된 보완 효과를 측정한다.
- 원본 결과: [evals/results/coverage-v7-harness.json](../evals/results/coverage-v7-harness.json). 입력·코드 SHA-256과 실패 이력을 포함한다. API 호출 179회, 입력 346799토큰, 출력 115217토큰.
- 중간 v3는 전체 실행에서 누락 탐지가 나빠져 채택하지 않았다. v4는 요구 분류가 답변 문맥에 따라 바뀌는 문제로 중단했고, v5는 한계 설명에 완전한 직접 답변 조건을 잘못 요구하는 규칙을 발견해 중단했다. v6는 40건을 시도했으나 참조 인용 검증 오류 2건으로 38건만 완결됐고, 오경보가 16개로 증가해 채택하지 않았다. v7에서는 문장 일부 발췌의 질문 판정, 요구 종류 구분, 개별 업무 식별 조건을 수정했다. 중간 기록을 모두 보존하며 부분 실행을 40건 결과라고 표현하지 않는다.
- 평가 과정의 전송·채점 기술 오류 재시도는 완료한 검사·보완 단계를 보존하고 실패한 단계만 재개한다. 유리한 답을 얻기 위해 완료 사례를 반복하지 않는다. C21 참조 채점의 비연속 문장 인용은 각 문장이 원문에 같은 순서로 정확히 존재할 때 그 사이 원문까지 포함한 연속 구간으로 복원했다. 판정·채점 기준은 변경하지 않았고 원래 판정과 복원 이력을 referenceEvidenceRepair에 보존했다. 없는 문장·의역·순서가 바뀐 인용은 복원하지 않는다.

## 발표에서 설명할 구축 기여와 개선 효과

우리 팀은 원문 기준의 요구 검사 계획을 고정하고, AI가 추출한 답변 근거를 코드로 검증하는 하네스를 구축·개선했다. 인용 일치·요구와 질문의 관계·기존 제공 정보·보완 횟수·보완 후 퇴행을 검사하고, 적용 규칙과 실패 이력을 저장한다.

같은 모델을 사용한 고정 합성 40건·100요구 비교에서 **누락 여부의 참조 판정 일치율은 89%에서 92%로 3%p 상승**했다. 이전은 누락 탐지 15개와 정상 판정 74개, 현재는 누락 탐지 18개와 정상 판정 74개를 합산한 값이다. 보완 후 누락은 4개에서 0개로 감소했고, 오경보는 8개로 같았다.

발표 문장: “저희는 원문에서 요구사항을 먼저 고정하고, AI가 추출한 근거를 코드로 검증하는 하네스를 구축했습니다. 동일 모델과 고정 합성 평가에서 누락 여부의 참조 판정 일치율을 89%에서 92%로 높였고, 보완 후 남은 누락을 4개에서 0개로 줄였습니다.”

이 수치는 AI 작성 참조 판정에 대한 개발셋 일치율이다. 법률 해석이나 서비스 전체의 정확도를 의미하지 않으며 독립 사람 검수는 남아 있다. 규칙·프롬프트·호출 구조·추론 설정을 함께 바꾼 전후 비교이므로 개별 규칙 하나의 효과를 분리해 입증한 결과로 표현하지 않는다.
