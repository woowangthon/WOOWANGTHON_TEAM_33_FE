# 이용허락을 확인한 평가 자료

`node evals/licensed-data/collect.cjs`로 원본과 라이선스 근거를 저장소 밖 `../licensed-data/`에 수집한다. `LICENSED_DATA_DIR`로 다른 경로를 지정할 수 있다. 유료 API·운영 DB·공개 접수함을 사용하지 않는다. 조건이나 파일 구조가 달라지면 중단한다.

| 자료 | 이용 조건 | 용도와 한계 |
| --- | --- | --- |
| [한국남동발전 환경관련 민원사항 현황](https://www.data.go.kr/data/15093026/fileData.do) 13건 | 이용허락범위 제한 없음. 제공기관·파일명·원본 링크·확인일을 보관 | 기관이 정리한 민원내용의 요약·요청 보존 확인. 시민 전체 원문·욕설 양성·실제 음성이 아님 |
| [2runo 욕설 감지 데이터셋](https://github.com/2runo/Curse-detection-data) 5,825문장 | MIT. Copyright (c) 2020 2runo. LICENSE 전문 동봉 | 커뮤니티 댓글의 표현 검사. 민원 사례로 표시하지 않으며 원본 0/1을 담당자 직접 공격의 정답으로 사용하지 않음 |

민원내용만 생성 모델에 전달하고 기관의 처리내용은 분리한다. 음성 검증에서 이 문장을 사람이 낭독하거나 TTS로 변환하면 각각 재연·합성 음성이라고 표시하고 원본 통화로 설명하지 않는다. 텍스트 출처의 이용허락이 실제 민원인의 녹음이나 음성 권리를 대신하지 않는다.

기존 지자체 게시판 3건은 이용허락이 확인되지 않은 과거 비공개 검토 기록이다. 새 공개 시연 자료로 배포하지 않는다. 포털 API에 적힌 허락을 다른 웹사이트·사례집 전체로 확대 적용하지 않는다.
