# 독립 검수 기록 양식

현재 상태: **미실시**. 이 문서는 검수 완료의 증거가 아니다.

프롬프트 작성·수정에 참여하지 않은 팀원이 `complaints-40.json`, `results/baseline.json`, 최신 보완 답변을 읽고 판단한다. 자동 판정과 결과 수치를 먼저 보지 않는 검수를 권장한다. 실제 검수자의 식별자와 날짜를 기록하며 AI가 대신 이름을 채우지 않는다.

상태: 답변됨 / 처리 불가·확답 불가 사유 안내 / 필요한 정보 질문 / 누락·불충분. 요구가 과도하게 분할되거나 원문에 없는 경우 별도로 표시한다. 필요한 질문은 그 정보가 실제로 제공되지 않았는지, 해당 요구에 정말 필요한지를 함께 확인한다.

불일치는 `docs/COVERAGE-RESULTS.md`에 보존한다. 참조 라벨을 수정할 때는 원래 판정, 새 판정, 변경 이유와 검수자를 남기고 새 결과 파일로 재평가한다. 기존 결과를 소급해서 유리하게 바꾸지 않는다.
