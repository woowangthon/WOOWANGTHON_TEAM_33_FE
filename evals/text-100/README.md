# 민원사이 텍스트 평가 입력 100건

국민권익위원회 공개 질의 50건과 각 질의를 바탕으로 욕설·직접 모욕을 추가한 합성 변형 50건입니다. 원문과 합성본은 `pairId`로 연결됩니다.

| 파일 | 내용 |
| --- | --- |
| [original-50.json](original-50.json) | 공개 질의 원문 50건 |
| [synthetic-50.json](synthetic-50.json) | 욕설·공격 표현을 추가한 합성 50건 |
| [complaints-100.csv](complaints-100.csv) | 제목과 본문을 한 번에 보는 표, Excel에서 열 수 있는 UTF-8 CSV |
| [dataset.json](dataset.json) | 기존 평가에 사용한 전체 입력과 AI 잠정 주석, 원본 파일 그대로 |
| [sources.json](sources.json) | 건별 공개 Q&A 번호, 수집 본문과 출처, 본문 해시 |
| [prompts.json](prompts.json) | 합성 작성·검토 지시 요약 |
| [preparation.json](preparation.json) | 작성·검토 과정과 표본 교체 기록 |
| [manifest.json](manifest.json) | 파일별 SHA-256과 구성 확인 결과 |

## 출처와 이용 조건

- 제공기관: 국민권익위원회
- 자료: [국민권익위원회_민원정책 질의응답조회서비스](https://www.data.go.kr/data/15074671/openapi.do)
- 이용허락범위: **이용허락범위 제한 없음** (2026-11-15 확인)
- 원문은 공개 Q&A의 질의 필드입니다. 최초 민원 제출 전문인지 확인되지 않았습니다.
- 합성본의 공격 표현은 평가를 위해 AI가 작성한 것으로, 원민원인의 실제 발언이 아닙니다.

## 구성과 사용

버전은 `acrc-natural-agent-v3`이며, 기존 입력을 바꾸거나 새로 생성하지 않고 공개했습니다. 공개 질의 50건은 보관된 수집 자료의 제목·본문과 모두 일치합니다.

검색어는 소음·폐기물·도로·하수·공원·건축·주차·복지·근로·교육입니다. `queryTopic`은 수집에 사용한 검색어이며, 공식 민원 분류나 확정된 내용 분류는 아닙니다. 표본 선정 후 감사글 1건을 같은 공개 API의 다른 질의로 교체한 이력은 `preparation.json`에 있습니다.

욕설·직접 공격 감지와 업무 사실·요청 보존을 검토하기 위한 데이터입니다. 50개 원문과 50개 변형은 서로 짝을 이루므로 독립된 실제 민원 100건으로 해석하지 않습니다. 학습/검증으로 나눌 경우 같은 `pairId`를 한 묶음으로 분리해야 합니다.

서비스 입력에는 `title`과 `body`만 사용합니다. `expectedDirectAttack`, `referenceFacts`, `attackSpans`는 평가용 AI 잠정 주석이므로 서비스 입력에 넣지 않습니다. 주석은 사람이 확정한 정답이 아닙니다. 이번 폴더에는 평가 점수나 서비스 실행 결과를 포함하지 않습니다.
