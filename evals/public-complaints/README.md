# 실제 공개 민원 평가

`sources.json`의 국민권익위원회 공개 결정례에서 **신청원인** 구간만 가져온다. 신청인이 직접 제출한 원문 전체와 같다고 주장하지 않는다. 결정사항·기관 답변·판단을 모델 입력에 넣지 않으며, 욕설이나 가상 민원을 추가하지 않는다.

## 수집과 사용 범위

- 현재 수집 경로는 공식 웹사이트다. 공공데이터포털 API 인증키가 없어 API 응답을 수집한 것은 아니다.
- API 데이터셋의 ‘이용허락범위 제한 없음’을 웹 페이지 전체의 이용허락으로 확대하지 않는다. 웹 원문 이용조건은 별도 확인이 필요하다.
- 원문 HTML·민원 발췌·실행 결과는 저장소 밖 `../acrc-evaluation/`에 보존하며 Git에 커밋하지 않는다. 웹 원문 재배포나 운영 DB 등록을 수행하지 않는다.
- 자료별 URL, 수집 시각, HTML 및 본문 SHA-256을 보존한다. 위치와 발생일 필드는 임의로 채우지 않는다.
- 저장소 밖 `../acrc-evaluation/reference.json`은 평가 전 작성한 개발 검토 기준이다. 실제 민원 발췌가 있어 Git에 커밋하지 않는다. 독립 사람 검수는 거치지 않았다. 생성·운영 자체 검증에 이 기준을 전달하지 않는다.

## 실행

```powershell
node evals/public-complaints/collect.cjs
node --env-file=.env.local evals/public-complaints/run.cjs --live
```

두 번째 명령은 기존 서비스 OpenAI API 키를 사용해 **유료 호출**을 한다. `--live` 없이 실행하면 호출하지 않는다. 결과가 있는 사례는 다시 호출하지 않으며, 코드·입력·모델이 달라졌으면 기존 결과를 덮어쓰지 않는다.

실패한 사례만 다시 확인할 때는 `--retry-failed`를 함께 지정한다. 최초 실패는 `previousRuns`에 보존한다. `retryable=false`인 잔액·인증 등의 실패나 결과를 알 수 없는 네트워크 호출은 이 옵션으로 반복하지 않는다. 이 스크립트는 Workflow SDK 전체 재시도·영속화를 실행하는 통합 시험은 아니다.

실제 `semanticPlan`, `generateAnalysis`, `verifyBusinessSummary`를 호출한다. 법령 검색과 DB·UI·음성 경로는 평가 범위가 아니다. 운영 배포는 하지 않는다.

## 해석 한계

현재 8건은 직접 욕설 공격 양성 사례가 없다. 폭언·협박 피해를 신고하는 사례와 욕설이 없는 민원을 통해 **욕설 인용 감지, 발화 역할 구분, 직접 공격 오탐, 요약의 근거·업무 보존**을 관찰한다. 직접 공격 탐지 재현율이나 전체 서비스 정확도를 산출하지 않는다.

자체 검증 통과와 품질 검토 통과는 구분한다. 요약 실패·수정·재시도도 결과에 남기며, 성공 답안을 고정하거나 원문 내용을 바꿔 통과시키지 않는다.

## 2026-11-14 실행 관찰

현재 하네스 v3 / gpt-6-luna로 8건을 검사했다. API 36회 호출 후 자체 요약 검증 7건 통과, 1건 실패였다. 원문 대조에서는 통과 7건 중 1건에 진술 주체 혼동 가능성이 남았다. 도로 소음 사례는 연속 발췌 불일치로 최초 호출과 재시도 3회 모두 차단되었다. 군 폭언 사례는 이미 요약에 있는 배경을 누락으로 지적해 불필요한 재생성이 있었다.

욕설·위협·모욕 인용 4개는 모두 제3자 발언으로 분류되었다. 분류까지 실행된 7건에서 직접 공격 오탐은 없었지만, 직접 공격 양성 사례가 없으므로 재현율은 측정하지 않았다. 원문·결과·실패 이력은 비공개 로컬 평가 폴더에 보존한다. 운영 DB 등록과 배포는 하지 않았다. 자동 검사 160개 및 TypeScript 검사를 통과했다.
