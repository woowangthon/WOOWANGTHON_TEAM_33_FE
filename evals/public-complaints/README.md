# 실제 공개 민원 평가

`sources.json`의 국민권익위원회 공개 결정례에서 **신청원인** 구간만 가져온다. 신청인이 직접 제출한 원문 전체와 같다고 주장하지 않는다. 결정사항·기관 답변·판단을 모델 입력에 넣지 않으며, 욕설이나 가상 민원을 추가하지 않는다.

## 수집과 사용 범위

- 현재 수집 경로는 공식 웹사이트다. 공공데이터포털 API 인증키가 없어 API 응답을 수집한 것은 아니다.
- API 데이터셋의 ‘이용허락범위 제한 없음’을 웹 페이지 전체의 이용허락으로 확대하지 않는다. 웹 원문 이용조건은 별도 확인이 필요하다.
- 원문 HTML·민원 발췌·실행 결과는 저장소 밖 `../acrc-evaluation/`에 보존하며 Git에 커밋하지 않는다. 웹 원문 재배포나 운영 DB 등록을 수행하지 않는다.
- 자료별 URL, 수집 시각, HTML 및 본문 SHA-256을 보존한다. 위치와 발생일 필드는 임의로 채우지 않는다.
- 저장소 밖 `../acrc-evaluation/reference.json`은 평가 전 작성한 개발 검토 기준이다. 실제 민원 발췌가 있어 Git에 커밋하지 않는다. 독립 사람 검수는 거치지 않았다. 생성·운영 자체 검증에 이 기준을 전달하지 않는다.

## 실행

```powershell
node evals/public-complaints/collect.cjs
node --env-file=.env.local evals/public-complaints/run.cjs --live
```

두 번째 명령은 기존 서비스 OpenAI API 키를 사용해 **유료 호출**을 한다. `--live` 없이 실행하면 호출하지 않는다. 결과가 있는 사례는 다시 호출하지 않으며, 코드·입력·모델이 달라졌으면 기존 결과를 덮어쓰지 않는다.

실패한 사례만 다시 확인할 때는 `--retry-failed`를 함께 지정한다. 최초 실패는 `previousRuns`에 보존한다. `retryable=false`인 잔액·인증 등의 실패나 결과를 알 수 없는 네트워크 호출은 이 옵션으로 반복하지 않는다. 이 스크립트는 Workflow SDK 전체 재시도·영속화를 실행하는 통합 시험은 아니다.

실제 `semanticPlan`, `generateAnalysis`, `verifyBusinessSummary`를 호출한다. 법령 검색과 DB·UI·음성 경로는 평가 범위가 아니다. 운영 배포는 하지 않는다.

### 공개 게시판 추가 표본

사용자는 공개 민원을 로컬에서 검토·평가하도록 지시했다. 원문을 변경하거나 욕설을 덧붙이지 않고 직접 욕설·피해 신고·발화 맥락을 비교한다. 이 추가 자료는 `../municipal-evaluation/`에 별도로 보관한다.

```powershell
$env:PUBLIC_COMPLAINT_EVAL_DIR='../municipal-evaluation'
node --env-file=.env.local evals/public-complaints/run.cjs --live
```

`municipal-source.cjs`는 게시판 본문에서 기관 답변을 제외한다. 현재 공식 페이지 HTML로 받은 자료와 검색 색인의 본문 스냅샷으로 받은 자료를 출처 메타데이터에 구분하며, 오류 페이지를 정상 민원으로 사용하지 않는다. `reference.json`과 `real-complaints.json`은 선택한 평가 폴더에 있어야 한다. 표본의 예상 역할·요청 기준은 실행 전에 기록하고 생성기에는 전달하지 않는다.

## 해석 한계

기존 결정례 8건은 직접 욕설 공격 양성 사례가 없다. 폭언·협박 피해를 신고하는 사례와 욕설이 없는 민원을 통해 **욕설 인용 감지, 발화 역할 구분, 직접 공격 오탐, 요약의 근거·업무 보존**을 관찰한다. 추가 게시판 3건에는 직접 공격 양성 사례 1건을 포함했지만, 적은 개발 표본이므로 직접 공격 탐지 재현율이나 전체 서비스 정확도를 산출하지 않는다.

자체 검증 통과와 품질 검토 통과는 구분한다. 요약 실패·수정·재시도도 결과에 남기며, 성공 답안을 고정하거나 원문 내용을 바꿔 통과시키지 않는다.

## 2026-11-14 실행 관찰

하네스 v3 / gpt-6-luna로 기존 8건을 검사했다. API 36회 호출 후 자체 요약 검증 7건 통과, 1건 실패였다. 원문 대조에서는 통과 7건 중 1건에 진술 주체 혼동 가능성이 남았다. 도로 소음 사례는 연속 발췌 불일치로 최초 호출과 재시도 3회 모두 차단되었다. 군 폭언 사례는 이미 요약에 있는 배경을 누락으로 지적해 불필요한 재생성이 있었다.

욕설·위협·모욕 인용 4개는 모두 제3자 발언으로 분류되었다. 분류까지 실행된 7건에서 직접 공격 오탐은 없었지만, 직접 공격 양성 사례가 없으므로 재현율은 측정하지 않았다. 원문·결과·실패 이력은 비공개 로컬 평가 폴더에 보존한다. 운영 DB 등록과 배포는 하지 않았다. 자동 검사 160개 및 TypeScript 검사를 통과했다.

### 추가 게시판 3건 · 하네스 v4

동대문구 DDM-14323(흡연 단속 이의·직접 욕설), 기장군 GIJANG-218271(방파제 출입 제한·제3자 욕설 피해), 도봉구 DOBONG-12732925(반려견 배설물 방치·발화 대상 비교)를 사용했다. 동대문구·도봉구는 검색 색인의 본문 스냅샷, 기장군은 공식 사이트 HTML로 수집했다. 현재 페이지를 직접 읽은 자료와 색인 자료를 혼동하지 않는다.

v3 선행 실행은 API 12회, 자체 검증 1건 통과·2건 실패였다. 동대문구는 발췌 불일치, 도봉구는 검색어 최소 길이 스키마 오류로 중단되었다. 기록은 `baseline-v3/`에 보존한다.

v4 실행은 API 18회, 입력 52,056·출력 22,814토큰으로 자체 요약 검증 3건이 통과했다. 동대문구의 직접 욕설은 `caution`, 기장군의 피해 신고는 `reported_speech`·`normal`로 분류했다. 하지만 원문과 대조한 개발 검토에서는 동대문구의 분납 제한 근거 질문 약화, 기장군의 낚시금지구역 여부 질문 누락, 도봉구의 제3자 대상 표현·실제 개 지칭을 직접 공격으로 분류하고 `unclear` 위협에도 `threat` 수준을 낸 문제가 남았다. 자체 요약 검증 통과는 표현 분류의 정확성이나 요청 보존을 보증하지 않는다.

별도 확인에서 과거 도로 소음 실패 1건은 새 추출로 3회 호출 후 통과했다. 동대문구의 실제 실패 응답을 재생하고 복구만 실제 API로 1회 실행한 시험에서는 연속 발췌 검사를 유지하면서 복구에 성공했다. 새 3건 실행과 도로 소음 실행에서는 최초 발췌가 일치해 복구 호출이 발생하지 않았다. 따라서 새 실행의 성공을 복구 기능만의 효과로 해석하지 않는다. 이 재생 시험은 새 전체 흐름 시험과 구분한다.

이번 추가 평가의 선행·현재·도로 소음·복구 재생 호출은 합계 34회다. 이전 8건의 36회와 구분한다. 현재 로컬 코드는 자동 검사 165개, TypeScript, 직접 Next.js 빌드를 통과했다. 실제 DB·운영 UI·전화 오디오·법령 검색과 답변 초안의 요청별 대응은 이번 API 평가 범위에 포함하지 않았다.

### 2026-11-15 오류 수정 · 하네스 v5

새 UI 대신 하네스 오류를 먼저 수정하라는 사용자 지시에 따라 같은 3건으로 로컬 재검증했다. 최초 요청 후보·원문 대조와 후보별 보존/중복/제외 기록, 고정 R ID를 통한 재작성 후 요청 보존 검사, 요청 의도·대상·조건 확인, 발화자·대상·구체적 실행 의사 검사를 추가했다. 발췌의 공백 차이는 유일한 실제 원문 구간을 복사하고 정확한 문자열 검사로 재확인한다. 내용 차이나 모호한 대응은 자동 승인하지 않는다.

수정 중 첫 v5 실행은 API 17회로 3건 실패, 두 번째는 API 21회로 1건 통과·2건 실패였다. 발췌/문맥 불일치와 중복 요청 누적으로 인한 검증 실패도 보존한다. `v5-first-attempt/`, `v5-second-attempt/`에 서로 다른 코드 해시의 원본 결과를 남겼다. v4 결과도 `baseline-v4/`로 보존했다.

최신 코드 실행은 API 16회, 입력 55,016토큰(캐시 11,764 포함)·출력 22,330토큰으로 3건 모두 자체 검증을 통과했다. 동대문구는 `caution`을 유지하고 분납 제한의 법적 근거 질문을 보존했으며 건강 배경을 제외했다. 기장군은 `reported_speech`·`normal`이며 낚시금지구역 질의·계도·사과문 요청을 보존했다. 도봉구는 제3자 공격과 업무 비판으로 구분하고 `threat`에서 `normal`로 바뀌었다. 최종 사실 발췌는 모두 원문에 존재했고, 동대문구의 발췌 1개에서 원문 공백 정합 복구가 실제 사용되었다. 별도 표현 문맥 AI 복구는 이 최종 실행에서는 호출되지 않았으며 모의 회귀 검사로 종료·응답 불명확 시 중단을 확인했다.

동대문구의 수사적 반문을 별도 질문으로 남긴 점과 모호한 헌법 질문의 대상을 구체화한 부분은 개발 검토상 추가 확인이 필요하다. 자동 통과 3건을 의미 정확도 100%로 표현하지 않는다. v5 수정 중 호출은 총 54회이며, 앞선 34회나 기존 결정례 8건의 호출과 별도다. 자동 검사 181개·타입 검사·직접 Next.js 빌드를 통과했다. 원문·참조 기준·욕설을 바꾸거나 사례별 정답을 추가하지 않았고 운영 등록·배포·Git push는 하지 않았다.

### 2026-11-15 반영과 이용허락 확인 자료

위 기록 이후 사용자가 반영을 지시하여 런타임 소스 `2635892`를 담당자·시민 운영 사이트에 배포했다. 두 프로젝트 READY와 운영 도메인 응답을 확인했다. 이전 게시판 3건은 공개 시연 데이터로 재배포하지 않는다. 이후 출처는 `evals/licensed-data/sources.json`을 기준으로 한다.

한국남동발전의 이용허락 제한 없는 CSV 13건과 MIT인 2runo 댓글 5,825문장을 원본·허락 근거·해시와 함께 저장소 밖에 수집했다. 민원은 기관이 정리한 짧은 내용이고 댓글은 민원이 아니다. 본문을 합치거나 욕설을 덧붙이지 않는다. CSV의 처리내용을 입력에서 제외한 민원 3건(1·4·9행)은 v5 자체 요약·요청 검증을 통과했다. API 12회, 입력 19,831·출력 3,500토큰이며 앞선 게시판 평가와 구분한다. 통화 텍스트 분기의 댓글 3문장(2·27·33행) 검사도 사전에 정한 직접 공격 유무 기준과 일치했다. 27행의 세부 분류는 `unclear`였으므로 정확한 제3자 분류 성공으로 표현하지 않는다. 이 3문장 검사는 API 3회이며 STT·실제 음성을 검사하지 않았다.

운영 통화 티켓 → WSS → 실제 STT 연결 시작, 무음 프레임 양방향 전달, 수동 보호·복구·종료를 별도 점검했다. 첫 검사 스크립트는 담당자 수신 프레임의 필드를 잘못 확인하여 시간 초과했고, 그 기록을 보존한 뒤 실제 프로토콜의 `payload`에 맞춰 재검사하여 통과했다. 이 점검은 실제 마이크·스피커, 실제 발화 STT, 자동 음성 욕설 차단 성능을 대신하지 않는다. 통화 단위 검사 31개도 통과했다. 운영 접수 데이터는 추가하지 않았다.
